# Reproducibility Specification & Guidelines

This document provides complete instructions and specifications for reproducing all experimental findings, counterfactual audits, ground-truth benchmark validations, and statistical analyses reported in the manuscript.

---

## 1. Environment & System Requirements

### Hardware & OS Specifications
* **Operating System**: Linux / macOS / Windows 10/11
* **Python Version**: Python 3.11+
* **Containerization**: Docker 20.10+ and Docker Compose 2.0+ (optional)

### Dependency Specification
All Python dependencies are pinned to exact versions in `requirements.txt`:
```txt
numpy==1.26.4
scipy==1.13.0
tqdm==4.66.4
ijson==3.3.0
matplotlib==3.8.4
pytest==8.2.0
```

---

## 2. Experimental Parameters & Random Seeds

To guarantee deterministic reproduction, all experimental scripts set explicit random seeds:
* **Primary Seed**: `seed = 42` (used across counterfactual audits, baseline profile generation, and ground-truth benchmark runs).
* **Sensitivity Analysis Seeds**: `seeds = [42, 123, 999]` (used to verify cross-seed stability across Monte Carlo sampling budgets).
* **Clustered Bootstrap**: `n_bootstraps = 1000` resamples clustered by prompt task (`seed = 42`).

### Generation Decoding Settings (API Calls)
* **Google Gemini 2.5 Flash** (`gemini-2.5-flash`): Default API decoding parameters (`temperature = 1.0`, `top_p = 0.95`), 5 independent generations per prompt task.
* **xAI Grok-Code-Fast-1** (`grok-code-fast-1`): Explicitly set `temperature = 0.7` (via OpenAI SDK), 5 independent generations per prompt task.


---

## 3. Directory Layout

* `data/dataset/prompts_unified_new.jsonl`: 343 standardized `@dataclass` prompts.
* `data/generated_functions_unified_new/`: 1,715 Python code samples generated by Gemini 2.5 Flash.
* `data/generated_functions_grok/`: 1,715 Python code samples generated by Grok-Code-Fast-1.
* `data/ground_truth_benchmark.json`: 30 synthetic functions with known ground truth across 5 categories.
* `src/`: Python source code for auditing, counterfactual testing, statistical analysis, and plot generation.
* `tests/test_auditor.py`: Unit test suite verifying auditor components.
* `reports/`: Execution outputs, JSON reports, and summary markdown documents.

---

## 4. How to Run (Native Python)

1. Install exact dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run Unit Tests:
   ```bash
   python -m unittest tests/test_auditor.py
   ```

3. Run Counterfactual Protected Bias Audit:
   ```bash
   python src/run_counterfactual_audit.py
   ```

4. Run Ground-Truth Benchmark Validation:
   ```bash
   python src/evaluate_ground_truth_benchmark.py
   ```

5. Run Behavioral Inconsistency Evaluation:
   ```bash
   python src/evaluate_behavioral_inconsistency.py
   ```

6. Run Statistical Significance Tests & Domain Breakdown:
   ```bash
   python src/analyze_statistical_rigor.py
   ```

7. Run Sampling Budget Sensitivity Analysis:
   ```bash
   python src/run_sensitivity_analysis.py
   ```

---

## 5. How to Run (Docker Container)

Build and run using Docker Compose:

* **Run Unit Tests**:
  ```bash
  docker compose run test
  ```

* **Run Counterfactual Audit**:
  ```bash
  docker compose run auditor
  ```

* **Run Ground-Truth Benchmark Validation**:
  ```bash
  docker compose run benchmark
  ```

* **Run Statistical Analysis**:
  ```bash
  docker compose run statistical
  ```
